🐙 發佈到 GitHub Pages

照以下步驟，5 分鐘就能得到永久公開連結（完全免費）：

  1. 登入 github.com，右上角 ＋ → New repository
  2. Repo 名稱填 trip，選 Public，按 Create
  3. 進入 repo 頁面 → Add file → Upload files，上傳這個 index.html
  4. Settings → Pages，Source 選 main branch，按 Save
  5. 約 1 分鐘後，網址為：https://你的帳號.github.io/trip/
  6. 點行程表工具列的「🔗 共用連結」，把帶行程資料的網址傳給夥伴
