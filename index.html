🐙 發佈到 GitHub Pages

照以下步驟操作，就能得到永久公開連結（免費）：

  1. 登入 github.com，點右上角 ＋ → New repository
  2. Repository 名稱填 trip（或任意名稱），選 Public，按 Create
  3. 在 repo 頁面按 Add file → Upload files，上傳這個 index.html 檔案
  4. 進入 repo 的 Settings → Pages，Source 選 main branch，按 Save
  5. 等約 1 分鐘，你的行程頁面網址就是：
    https://你的帳號.github.io/trip/
  6. 點「🔗 共用連結」把行程資料附加在網址後，就能分享給所有夥伴！

⚠️ 重置為空白行程表？

這會清除所有行程內容，建立一個空白模板讓你重新輸入。此操作無法復原。
